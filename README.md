# 盲棋(中国象棋变体)

> 一个纯前端的中国象棋盲棋变体游戏。30 枚暗棋身份随机,翻棋与走棋并行,单文件实现,打开即玩。

## 玩法

### 开局

- 棋盘为 9×10 中国象棋棋盘。除帅(红)/将(黑)外,其余 30 个棋位为**暗棋**,身份随机洗牌分配(15 红 + 15 黑,即双方的车马象士炮各 2、兵/卒各 5)
- 帅、将开局明置,固定位于双方底线正中;暗棋一律显示为「?」

### 回合机制(核心特色)

- 每回合**必须走一步棋**,**可选翻一枚暗棋**(最多一次)
- 先走后翻:走完可翻一枚,翻完自动换边;不想翻就点「结束回合」
- 先翻后走:翻完必须走,走完自动换边
- 键盘快捷键:E 结束回合,Esc 取消选择,胜利后 Enter 开新局

### 暗棋规则

- 未翻开的棋子**可以移动**,按其所在位置的原始棋种规则走(炮位上的暗棋按炮走)
- 翻开后按真实身份走;暗棋翻开的瞬间才揭晓阵营
- 走到暗棋上视为吃子:动画展示被吃棋子的真实身份后移除

### 完整棋规

- 马腿、象眼、炮翻山
- 兵/卒过河前只进,过河后可横走
- 帅/将限九宫,飞将禁止(两将不能同列无遮挡)

### 胜负

- 吃掉对方帅/将即获胜,弹出胜利结算
- 悔棋最多回退 20 步;吃子列表按阵营分列展示

## 快速开始

浏览器直接打开 `index.html` 即可,无需任何依赖和构建。
